# Week 5

## Lab

The main Week 5 lab compares affine and neural-network classifiers on the same noisy XOR dataset. The first notebook is a complete hands-on experiment: you implement and fit the network, plot its empirical loss and mistakes, and inspect its decision boundaries and learned features.

Notebooks 2 and 3 are optional follow-up material on modular implementations. Work through those two in order if you continue.

Run the supplied affine comparison, then complete guided coding exercises to build and fit a neural network. Compare the models and inspect how the hidden feature values change. Worked answers follow each exercise.
